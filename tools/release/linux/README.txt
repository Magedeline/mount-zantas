Mount Zantas {VERSION} for Linux (x64)

Run it:  ./MountZantas   (or double-click it in your file manager)
If it won't start, make it executable first:  chmod +x MountZantas

You need your own copy of Celeste (Steam, itch, or any folder). Settings live in ~/.local/share/MountZantas.
Report problems at https://github.com/Magedeline/mount-zantas/issues
