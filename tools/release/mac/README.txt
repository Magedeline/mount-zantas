Mount Zantas {VERSION} for macOS

1. Drag "Mount Zantas.app" to Applications.
2. The app is not signed by Apple yet, so the first time: right-click it, choose Open, then Open again.
   (Or run: xattr -dr com.apple.quarantine "/Applications/Mount Zantas.app")

This build is Intel (x64). On Apple Silicon Macs it runs through Rosetta 2; macOS offers to install Rosetta if needed.
You need your own copy of Celeste. Settings live in ~/Library/Application Support/MountZantas (or ~/.local/share/MountZantas).
Report problems at https://github.com/Magedeline/mount-zantas/issues
